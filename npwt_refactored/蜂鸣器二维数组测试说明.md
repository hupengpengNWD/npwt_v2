# 蜂鸣器二维数组测试说明

## 功能概述

已成功实现蜂鸣器二维数组配置功能，支持多种不同的时序模式切换。

## 硬件特性

蜂鸣器具有特殊的物理特性：
- 一旦通电就会以100-200ms的间隔连续鸣叫
- 不需要软件控制具体的鸣叫间隔
- 只需要控制开/关的时序

## 二维数组配置

### 当前支持的时序模式

```c
static const uint16_t g_buzzer_seq_2d_array[][2] = {
    {10, 3},    // 模式0：静500ms，响150ms (500ms/50ms=10, 150ms/50ms=3)
    {20, 3},    // 模式1：静1000ms，响150ms (1000ms/50ms=20, 150ms/50ms=3)
    {40, 3},    // 模式2：静2000ms，响150ms (2000ms/50ms=40, 150ms/50ms=3)
    {60, 3},    // 模式3：静3000ms，响150ms (3000ms/50ms=60, 150ms/50ms=3)
    {80, 3},    // 模式4：静4000ms，响150ms (4000ms/50ms=80, 150ms/50ms=3)
    {100, 3}    // 模式5：静5000ms，响150ms (5000ms/50ms=100, 150ms/50ms=3)
};
```

### 时间单位说明

- 每个数值的单位是 **tick**
- 1 tick = 50ms（蜂鸣器处理定时器周期）
- 例如：`{20, 20}` 表示开20×50ms=1000ms，关20×50ms=1000ms

## 按键控制

### 上键（Up Key）
- **单击**：切换到二维时序模式（循环切换不同模式）

### 下键（Down Key）  
- **单击**：切换到一维时序模式（固定2秒周期）

## 使用方法

1. **开机**：长按确认键1秒开机
2. **测试蜂鸣器**：
   - 单击上键：切换到二维时序模式，蜂鸣器会按顺序循环播放不同模式
   - 单击下键：切换到一维时序模式，蜂鸣器固定2秒周期
3. **关机**：长按确认键3秒后松开

## 技术实现

### 核心组件

1. **pushpull.h/c**：底层蜂鸣器控制组件
   - 支持一维和二维数组模式
   - 状态机自动切换不同时序

2. **app_beep.h/c**：应用层蜂鸣器控制
   - 预定义多种时序模式
   - 提供模式切换接口

3. **app_button.h/c**：按键处理
   - 上键/下键控制蜂鸣器模式切换

### 关键函数

- `PushPull_Set2DSequence()`：设置二维时序数组
- `AppBeep_StartBeep2D()`：启动二维时序模式
- `AppBeep_SwitchTo2DSequence()`：切换到二维模式
- `AppBeep_SwitchToSequence()`：切换到一维模式

## 自定义时序

如需添加新的时序模式，可以修改 `app_beep.c` 中的 `g_buzzer_seq_2d_array` 数组：

```c
static const uint16_t g_buzzer_seq_2d_array[][2] = {
    {20, 20},   // 模式0：开1秒，关1秒
    {10, 10},   // 模式1：开0.5秒，关0.5秒
    // 添加新模式...
    {15, 5},    // 新模式：开0.75秒，关0.25秒
};
```
