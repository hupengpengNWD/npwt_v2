    紧急修复：main()启动时立即设置电源自锁
    
    【问题】
    用户测试：松开确认键后立即断电
    
    【根本原因】
    POWER_ON 设置太晚！
    - HAL_GPIO_Init() → LATC=0 → RC2=0
    - 之前在初始化后才设置 RC2=1
    - 如果用户在1秒检测期间松开按钮 → RC2=0 → 断电
    
    【关键理解】
    硬件电路可能需要MCU尽快设置RC2=1：
    - 按钮按下 → 电源上电 → MCU启动
    - MCU必须立即设置RC2=1 → 电源自锁
    - 然后用户才能安全松开按钮
    
    【修复方案】
    在 main() 函数的第一行立即设置POWER_ON：
    
    void main(void)
    {
        // ⭐ 第一优先级：立即自锁电源
        TRISCbits.TRISC2 = 0;  // RC2设为输出
        LATCbits.LATC2 = 1;    // POWER_ON = 1
    
        HAL_Watchdog_Clear();
        System_InitHardware();
        ...
    }
    
    时序：
    - t=0μs:   用户按下按钮，VDD上电
    - t=几μs:  main()开始执行
    - t=几μs:  RC2=1 自锁 ✅
    - t=几ms:  初始化完成
    - 用户随时松开按钮 → RC2=1保持供电 ✅
    
    【编译结果】
    ✅ Program space: 33627 bytes (51.3%)
    
    现在应该可以正常开机了！

    【问题现象】
    用户测试：按住确认键后屏幕背光打开，但松开按键后系统立即断电
    
    【根本原因】
    时序问题导致电源自锁失败：
    
    1. 用户按下按钮 → 电源上电 → main()开始执行
    2. HAL_GPIO_Init() 执行 → LATC = 0 → RC2 = 0
    3. 此时按钮还在按下，电路靠按钮保持导通
    4. 初始化继续，进入主循环
