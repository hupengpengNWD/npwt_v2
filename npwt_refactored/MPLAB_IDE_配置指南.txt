================================================================================
  MPLAB X IDE 下载配置指南
================================================================================

【问题】
提示：The target circuit may require more power than the debug tool can provide.

【原因】
✅ PICkit3 已成功连接到 PIC18F46J11 芯片
⚠️ 目标电路可能需要的电流超过 PICkit3 供电能力（~30mA）

================================================================================
配置方法：使用外部电源供电（推荐）
================================================================================

步骤1：配置 MPLAB X 项目
────────────────────────

1. 在 MPLAB X IDE 中，右键点击项目 "NWPT_VR"
   
2. 选择 "Properties" (属性)

3. 左侧选择：
   Conf: [default] → PICkit3PlatformTool

4. 右侧选择 "Power" 选项卡

5. 配置供电方式：
   ┌─────────────────────────────────────────┐
   │ Power target circuit from PICkit3       │
   │ ☐ (取消勾选 - 使用外部电源)              │
   │                                         │
   │ Voltage Level: 3.25                     │
   │ (这个值用于检测，不影响外部供电)         │
   └─────────────────────────────────────────┘

6. 点击 "Apply" 然后 "OK"


步骤2：硬件连接
────────────────

外部供电配置：
  
  外部电源（3.3V 或 5V）
    │
    ├─→ 目标板 VDD
    └─→ 目标板 GND
  
  PICkit3 连接：
    Pin 1 (MCLR) → 目标板 MCLR
    Pin 2 (VDD)  → 目标板 VDD  ← 只用于检测电压，不供电
    Pin 3 (GND)  → 目标板 GND  ← 必须共地
    Pin 4 (PGD)  → 目标板 RB7
    Pin 5 (PGC)  → 目标板 RB6


步骤3：下载程序
────────────────

1. 确保目标板已通过外部电源供电（LED 指示灯亮起）

2. 点击 MPLAB X IDE 工具栏上的：
   "Make and Program Device Main Project" 按钮
   （绿色箭头图标）

3. 或使用快捷键：Cmd + Shift + R

4. 观察输出窗口（Output）查看下载进度


================================================================================
如果使用 PICkit3 供电（仅限低功耗测试）
================================================================================

⚠️ 只适用于：
  - 测试最小系统（只有 MCU，无外设）
  - 电路板总功耗 < 20mA
  - 临时测试，不推荐长期使用

配置：
  项目 Properties 
  → PICkit3PlatformTool 
  → Power
  → ✅ 勾选 "Power target circuit from PICkit3"
  → Voltage Level: 3.25V


================================================================================
常见下载错误和解决方法
================================================================================

错误1：Target Device ID mismatch
────────────────────────────────
症状：芯片 ID 不匹配
原因：
  - 电源电压不稳定
  - ICSP 接线错误
  - 芯片损坏
解决：
  1. 检查供电电压（用万用表测量 VDD）
  2. 检查 PGC/PGD 接线
  3. 更换芯片测试


错误2：Failed to program device
────────────────────────────────
症状：编程失败
原因：
  - 电源不足
  - MCLR 被拉低
  - 芯片被代码保护
解决：
  1. 使用外部电源
  2. 检查 MCLR 上拉电阻（10K）
  3. 在 IDE 中执行 "Erase Device Memory"


错误3：Programming/Verify complete
────────────────────────────────
症状：这不是错误，是成功！
说明：程序已成功下载并验证


================================================================================
PIC18F46J11 引脚定义参考
================================================================================

ICSP 编程接口：
  Pin 1  - MCLR/VPP    (复位/编程电压)
  Pin 39 - RB6/PGC     (编程时钟)
  Pin 40 - RB7/PGD     (编程数据)
  Pin 11 - VDD         (电源 3.0V ~ 3.6V)
  Pin 12 - GND         (地)

电源引脚：
  VDD: Pin 11, Pin 32
  VSS: Pin 12, Pin 31

注意：PIC18F-J 系列工作电压范围：2.0V ~ 3.6V
      不要使用 5V 供电！


================================================================================
下载成功后的检查
================================================================================

✅ 观察输出窗口显示：
   Programming...
   Reading...
   Verifying...
   Programming/Verify complete
   
✅ 目标板开始运行：
   - LCD 显示开机 Logo
   - LED 指示灯正常
   - 系统进入待机模式

✅ 如果程序不运行：
   1. 检查配置位（mcu_config.h）
   2. 检查时钟设置
   3. 检查看门狗是否触发复位

  1. 目标板通电（外部 3.3V 电源）
  2. 连接 PICkit3 的 6 根线
  3. 打开 MPLAB X IDE
  4. 打开项目 NWPT_VR.X
  5. 点击绿色箭头按钮
  6. 等待 "Programming/Verify complete"
  7. 测试硬件功能
