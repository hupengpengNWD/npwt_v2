================================================================================
  未重构工程开机流程详细分析
================================================================================

【核心机制】
系统上电后进入 MOD_SYS 模式，必须按住确认键（KEY_C/KEY_OK）才能开机！


================================================================================
详细开机流程（时间线）
================================================================================

t=0ms: 系统上电
────────────────
main() 函数执行：
  1. SYS_OSC_Ini()      - 初始化振荡器（32MHz）
  2. Flash_Read()       - 读取配置参数
  3. SYS_IO_Ini()       - GPIO初始化
  4. SYS_TMR0_Ini()     - 定时器0初始化（20ms周期）
  5. SYS_TMR3_Ini()     - 定时器3初始化（1ms周期）
  6. SYS_ADCini()       - ADC初始化
  7. BAT_WarnFir()      - 首次电池检测
  8. GIE=1, PEIE=1      - 使能中断

初始状态：
  mod_main_a = MOD_SYS        // 系统初始化模式（值=0）
  key_start_tim = 0           // 按键计时器
  mod_tim_cnta = 0            // 模式计时器
  POWER_ON = 0                // 电源控制信号关闭


t=0~1000ms: 按键检测阶段（开机前50个周期 = 1秒）
──────────────────────────────────────────────

主循环每20ms执行一次 MODE_ProA()：

case MOD_SYS:
{
    if (mod_tim_cnta > 50)          // 第51个周期（1秒后）
    {
        if (mod_tim_cnta < 52)      // 第51-52个周期
        {
            // ⭐ 关键检查点：按键是否按住足够长时间
            if (key_start_tim < 30)  // 按键时间不足（少于30个周期 = 600ms）
            {
                mod_tim_cnta = 0;     // 复位计时器
                POWER_ON = 0;         // 关闭电源 ❌
                key_start_tim = 0;
                return;               // 直接返回，继续等待
            }
            else  // 按键时间足够（≥30个周期 = 600ms）
            {
                SYS_IniLcd();         // 初始化LCD
                POWER_ON = 1;         // 打开电源 ✅
                DRV_EN = 1;           // 使能驱动
                VAL2 = 1;             // 电磁阀2打开
            }
        }
        
        SetBlk();                     // 打开背光
        DISP_Sys100();                // 显示开机画面（100%）
        
        // 蜂鸣器控制
        if (mod_tim_cnta > 62)
            SPEAK = 0;                // 关闭蜂鸣器
        else
            SPEAK = 1;                // 开启蜂鸣器（哔一声）
    }
    else  // mod_tim_cnta <= 50（前1秒）
    {
        // ⭐ 按键检测：必须按住确认键
        if ((GET_KEY_VAL) == KEY_C)   // KEY_C = 0x38 (确认键)
        {
            key_start_tim++;          // 按键计时器递增
        }
        else
        {
            key_start_tim = 0;        // 松开按键，计时器清零
        }
    }
    
    mod_tim_cnta++;                   // 模式计时器递增
    
    // 开机画面显示时间
    if (mod_tim_cnta >= (7000/20))    // 7秒后（350个周期）
    {
        mod_main_a = MOD_WAT;         // 进入待机模式
        mod_tim_cnta = 0;
        key_val = key_val_bak = 0;
        BUZ_KeyCls();                 // 关闭蜂鸣器
        lock_cnt = 0;
        lock_flg = 0;
        key_flg_l = 1;
        DISP_Clear();                 // 清屏
        adc_zero = adc_ps0;           // 设置压力零点
    }
    else if (mod_tim_cnta >= (5000/20))  // 5秒后显示版本号
    {
        DISP_Ver();
    }
    
    break;
}


================================================================================
关键时间点总结
================================================================================

时间           mod_tim_cnta    动作
────────────   ─────────────   ───────────────────────────────────
0ms            0               系统上电，进入 MOD_SYS 模式
                               开始检测按键
0~1000ms       1~50            持续检测 KEY_C 是否按下
                               按下时 key_start_tim++ 
                               松开时 key_start_tim=0

1000ms         51-52           ⭐ 判断时刻：
                               if (key_start_tim < 30):
                                 → 复位，重新检测（关机）
                               else (key_start_tim >= 30):
                                 → POWER_ON=1（开机成功！）
                               
1020ms~5000ms  51~250          显示开机画面（LOGO）
                               蜂鸣器哔一声（1020-1240ms）

5000ms~7000ms  250~350         显示版本号

7000ms         350             进入待机模式 MOD_WAT


================================================================================
开机条件详解
================================================================================

【必要条件】
1. 在前1秒（mod_tim_cnta ≤ 50）内：
   - 必须持续按住确认键（KEY_C = 0x38）
   - key_start_tim 必须累计到至少30

2. 计算：
   - 每20ms检测一次按键
   - 前50个周期（1秒）可以累计最多50次
   - 要求至少30次 → 至少按住 30×20ms = 600ms

【不充分条件会导致】
- key_start_tim < 30 时：
  → POWER_ON = 0
  → mod_tim_cnta = 0
  → key_start_tim = 0
  → 回到起点，继续检测（设备不开机）


================================================================================
POWER_ON 信号的作用
================================================================================

#define POWER_ON LATCbits.LATC2  // RC2 引脚

作用：
  - 控制系统电源继电器或MOSFET
  - POWER_ON=0 → 设备关闭（或进入低功耗模式）
  - POWER_ON=1 → 设备保持开机状态

开机后必须维持 POWER_ON=1，否则设备会断电！


================================================================================
关机逻辑（MODE_Pro 函数）
================================================================================

关机条件：
  1. 长按关机键（KEY_CL = 0xb8，即 KEY_C 长按）
  2. 电池电量过低（自动关机）
  3. 错误过多（自动关机）

关机动作：
  - 保存参数到Flash
  - POWER_ON = 0  ← 关键：断电
  - 进入 MOD_OFF 模式


================================================================================
重构工程需要实现的逻辑
================================================================================

【核心要求】
1. 系统上电后进入初始化模式（类似 MOD_SYS）
2. 前1秒内检测确认键是否持续按下
3. 累计按键时间 ≥ 600ms 才允许开机
4. 开机后设置 POWER_ON=1（RC2=1）
5. 显示开机画面和版本号
6. 7秒后进入待机模式

【当前重构工程的问题】
很可能缺少以下内容：
  ✗ 没有初始化模式（MOD_SYS）
  ✗ 没有开机按键检测逻辑
  ✗ 没有 POWER_ON 信号控制
  ✗ 直接进入工作模式

void System_InitMode(void)
{
    static uint16_t init_timer = 0;
    static uint16_t key_hold_time = 0;
    
    init_timer++;
    
    if (init_timer <= 50)  // 前1秒
    {
        // 检测确认键
        if (Key_Scan() == KEY_CONFIRM)
        {
            key_hold_time++;
        }
        else
        {
            key_hold_time = 0;
        }
    }
    else if (init_timer == 51)  // 判断时刻
    {
        if (key_hold_time < 30)  // 按键时间不足
        {
            // 关机：复位计时器
            init_timer = 0;
            key_hold_time = 0;
            HAL_PowerOn_Release();  // POWER_ON=0
            return;
        }
        else  // 按键时间足够
        {
            // 开机成功
            HAL_PowerOn_Hold();     // POWER_ON=1
            LCD_Init();
            // 显示开机画面
            LCD_DisplayStartup();
            // 蜂鸣器提示
            HAL_Buzzer_Beep(50);
        }
    }
    else if (init_timer >= 350)  // 7秒后
    {
        // 进入待机模式
        g_system.mode = MODE_STANDBY;
        init_timer = 0;
    }
}
