================================================================================
重要配置说明
================================================================================

1. 振荡器配置
─────────────
   OSC = INTOSCPLL
   
   含义：使用内部 8MHz RC 振荡器 + 4倍PLL
   最终系统时钟：32MHz
   
   优点：
   - 不需要外部晶振
   - 降低成本和PCB面积
   - 启动速度快
   
   注意：
   - 在 mcu_config.h 中定义 _XTAL_FREQ = 8000000UL
   - 实际 Fosc = 32MHz（内部PLL后）
   - 指令周期 = Fosc/4 = 8MHz


2. 看门狗配置
─────────────
   WDTEN = ON
   WDTPS = 16384
   
   超时时间计算：
   - 基础周期：约 4ms
   - 分频后：4ms × 16384 = 65.536秒
   
   代码中需要：
   - 定期调用 CLRWDT() 或 HAL_Watchdog_Clear()
   - 超时时间内必须喂狗，否则复位


3. 代码保护
─────────────
   CP0 = OFF
   WPDIS = OFF
   
   说明：
   - 所有代码保护和写保护都已禁用
   - 方便开发和调试
   - 生产环境可以启用保护


4. 调试配置
─────────────
   注意：没有 DEBUG 配置位
   
   PIC18F-J 系列不需要 DEBUG 配置位
   - MPLAB X 会自动处理调试模式
   - 下载时选择 "Debug" 或 "Release" 即可


================================================================================
下载配置建议
================================================================================

MPLAB X IDE 项目属性：
────────────────────

1. PICkit3 Power 选项：
   ☐ Power target circuit from PICkit3  (取消勾选，使用外部供电)
   Voltage Level: 3.25V

2. PICkit3 Program Options：
   Program Speed: 1 或 0.5  (降低速度，提高可靠性)
   Erase before program: ✅ (编程前擦除)

3. 供电要求：
   - 目标板外部供电：3.0V ~ 3.6V
   - 电源稳定性要求高
   - 建议加 100μF + 0.1μF 去耦电容


================================================================================
配置文件包含关系
================================================================================

main.c
  └─→ #include "Core/Inc/mcu_config.h"
       └─→ #include "config_bits.h"
            └─→ 所有 #pragma config 语句
            └─→ #include <xc.h>


正确的编译顺序：
1. config_bits.h 中的配置位首先被处理
2. 配置位写入到芯片配置存储器
3. <xc.h> 提供寄存器定义
4. mcu_config.h 提供宏定义和延时函数
5. main.c 使用这些定义
