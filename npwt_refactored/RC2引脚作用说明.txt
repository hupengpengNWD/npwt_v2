================================================================================
  RC2 引脚作用详细说明
================================================================================

【定义】
#define POWER_ON LATCbits.LATC2

引脚：PIC18F46J11 的 RC2 (Pin 13)
方向：输出
功能：电源自锁控制


================================================================================
硬件电路原理
================================================================================

典型的电源自锁电路：

                    +--------------------+
                    |                    |
    电源开关/按钮 ---|                    |
    (KEY_CONFIRM)   |    电源管理电路    |--- VDD (3.3V)
                    |   (MOSFET/继电器)   |
                    |                    |
    RC2(POWER_ON)---|                    |
                    +--------------------+
                         |
                        GND

工作原理：
─────────

1. 初始状态（未上电）：
   - 电源开关未按下
   - RC2 = 不确定
   - VDD = 0V
   - 系统未上电

2. 用户按下电源开关（确认键）：
   - 电源开关闭合
   - VDD 开始供电
   - 系统启动运行
   - MCU 检测到按键持续按下

3. MCU 设置 POWER_ON=1（RC2=1）：
   - RC2 输出高电平
   - 电源管理电路保持导通（自锁）
   - 即使用户松开按键，VDD 也继续供电
   - 系统保持运行

4. 关机时 MCU 设置 POWER_ON=0（RC2=0）：
   - RC2 输出低电平
   - 电源管理电路断开
   - VDD 断电
   - 系统关机


================================================================================
代码中的使用
================================================================================

【开机时】
────────
在 MOD_SYS 模式的第51个周期（1秒后）：

if (key_start_tim >= 30)  // 确认键按住 ≥ 600ms
{
    POWER_ON = 1;  // ⭐ 设置 RC2=1，电源自锁
    
    // 此时即使用户松开按键，电路也会保持供电
    // MCU 继续运行
}
else
{
    POWER_ON = 0;  // RC2=0，电源断开
    // 系统关机，重新等待按键
}


【关机时】
────────
在 MOD_OFF 模式等待1秒后：

// 保存配置到 Flash
Flash_SaveSystemSettings(...);

// 关闭所有外设
ClrBlk();
AUDIO_EN = 0;

// 断电
POWER_ON = 0;  // ⭐ 设置 RC2=0，释放电源自锁

// 此时硬件电路断开，VDD 消失
// MCU 停止运行


================================================================================
PORTC 引脚完整分配
================================================================================

从 npwt_dis_sys_ini_00.c 的注释：

PORTC: RC0-1输入（电池状态），RC2-7输出（电源、气泵、LED）

具体分配（从 include.h）：
─────────────────────

RC0: BAT_GOOD    - 输入，电池电量良好信号
RC1: BAT_CHARGE  - 输入，电池充电状态信号
RC2: POWER_ON    - 输出，电源自锁控制 ⭐⭐⭐
RC3: DRV_EN      - 输出，驱动使能
RC4: GRE         - 输出，绿色LED
RC5: YEL         - 输出，黄色LED
RC6: (未定义)    - 预留
RC7: PUMP        - 输出，气泵控制

配置：
TRISC = 0b00000011
        ││││││└└─ bit0-1: 输入（电池状态）
        └└└└└└─── bit2-7: 输出（控制信号）


================================================================================
为什么需要 POWER_ON 自锁？
================================================================================

【问题】
如果没有自锁电路，用户松开电源按钮后，系统会立即断电。

【解决】
使用 POWER_ON 自锁：
1. 用户按下按钮 → 系统上电启动
2. MCU 检测到按键 → 设置 POWER_ON=1
3. POWER_ON=1 → 电源电路保持导通
4. 用户松开按钮 → 系统仍然保持运行
5. 需要关机时 → MCU 设置 POWER_ON=0 → 断电

【优势】
✅ 用户不需要一直按住按钮
✅ MCU 可以控制关机时机
✅ 可以在关机前保存数据
✅ 防止意外断电


================================================================================
硬件电路示例（常见方案）
================================================================================

方案1：MOSFET 自锁电路
───────────────────────

                    VIN (电池/USB)
                      |
                      | 
                   [MOSFET]
              G/     |     \D
               /     |      \
    RC2 ------+      |       +------ VDD (3.3V)
              \      |      /
               \S    |     /
                     |
    按钮 -------+----+
                |
               GND

工作原理：
- 按下按钮 → MOSFET 导通 → VDD 上电
- MCU 启动后设置 RC2=1 → MOSFET 栅极保持高电平 → 自锁
- 松开按钮 → MOSFET 仍然导通（RC2=1）
- MCU 设置 RC2=0 → MOSFET 关断 → VDD 断电


方案2：继电器自锁电路
───────────────────────

                    VIN
                      |
                   [继电器]
                   常开触点
                      |
                   +--+--+
                   |     |
    按钮 -----+----+     +---- VDD
              |          |
    RC2 ------+          |
              |          |
             GND        GND

工作原理：
- 按下按钮 → 继电器吸合 → VDD 上电
- MCU 设置 RC2=1 → 继电器保持吸合 → 自锁
- 松开按钮 → 继电器仍然吸合（RC2=1）
- MCU 设置 RC2=0 → 继电器释放 → VDD 断电

【关机验证】

【HAL 实现】
在 hal_gpio.c 中应该有：
  void HAL_Power_Hold(void)    { LATCbits.LATC2 = 1; }
  void HAL_Power_Release(void) { LATCbits.LATC2 = 0; }


================================================================================
重要提示
================================================================================

⚠️ 如果您的硬件电路没有 POWER_ON 自锁功能：

1. 检查电路板上是否有 RC2 连接的 MOSFET 或继电器
2. 如果没有，系统可能无法正常开关机
3. 可能需要修改代码，注释掉 POWER_ON 相关逻辑

⚠️ 如果硬件有 POWER_ON 自锁，但逻辑相反（低电平有效）：

需要修改 HAL 函数：
  void HAL_Power_Hold(void)    { LATCbits.LATC2 = 0; }  // 反逻辑
  void HAL_Power_Release(void) { LATCbits.LATC2 = 1; }

⚠️ 调试时注意：

如果通过 PICkit3 调试器供电，POWER_ON 信号可能不起作用
（因为 VDD 是由调试器提供的，不受 RC2 控制）
