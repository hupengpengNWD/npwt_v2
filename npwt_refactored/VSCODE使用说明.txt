================================================================================
  VSCode 中编译和下载固件的方法
================================================================================

【环境要求】
✅ MPLAB X v5.40 已安装
✅ XC8 编译器 v3.00 已安装
✅ PICkit3 调试器已连接
✅ 目标板 PIC18F46J11 已供电


================================================================================
方法1：使用命令行（最直接）
================================================================================

在 VSCode 终端中执行：

  # 1. 进入项目目录
  cd /Users/petrinamigdal/.../npwt_refactored
  
  # 2. 编译
  make -C NWPT_VR.X
  
  # 3. 下载到 PICkit3
  /Applications/microchip/mplabx/v5.40/mplab_platform/mplab_ipe/bin/ipecmd.sh \
    -P18F46J11 \
    -TPPK3 \
    -FNWPT_VR.X/dist/default/production/NWPT_VR.X.production.hex \
    -M \
    -OL


================================================================================
方法2：使用下载脚本（最简单）
================================================================================

在 VSCode 终端中执行：

  # 一键编译并下载
  ./program.sh

脚本会自动：
  ✅ 清理旧文件
  ✅ 重新编译
  ✅ 下载到 PICkit3
  ✅ 显示结果


================================================================================
方法3：使用 VSCode 任务（最方便）
================================================================================

已配置 .vscode/tasks.json，提供以下任务：

1. 【编译】
   - 按 Cmd+Shift+B
   - 或 Cmd+Shift+P → "Run Task" → "编译 NWPT"

2. 【清理并编译】
   - Cmd+Shift+P → "Run Task" → "清理并编译"

3. 【下载到 PICkit3】
   - Cmd+Shift+P → "Run Task" → "下载到 PICkit3"
   - 会自动先编译，然后下载

4. 【编译并下载】
   - Cmd+Shift+P → "Run Task" → "编译并下载"
   - 一键完成编译+下载


================================================================================
常见问题
================================================================================

Q1: 下载失败，提示 "Target Device ID (0x0) does not match"
A1: 检查：
    - PICkit3 是否正确连接到目标板
    - 目标板是否供电
    - ICSP 接线是否正确（VPP, VDD, GND, PGC, PGD）

Q2: 下载失败，提示 "Could not connect to tool"
A2: 检查：
    - PICkit3 USB 连接
    - 关闭 MPLAB X IDE（避免占用设备）
    - 拔插 PICkit3 重试

Q3: 编译成功但下载失败
A3: 手动执行：
    cd NWPT_VR.X/dist/default/production
    ls -lh *.hex
    确认 .hex 文件是否生成

Q4: 需要调试怎么办？
A4: 命令行工具只能下载，调试请使用 MPLAB X IDE
