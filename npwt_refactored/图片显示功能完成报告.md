## 💻 技术实现

### 1. 图片存储格式
```c
// 全屏图片：128x64像素，8页 × 128列 = 1024字节
const uint8_t LOGO_STARTUP_IMAGE[1024] = { ... };

// 电池图标：24x16像素，2页 × 24列 = 48字节
const uint8_t BATTERY_ICON_0[48] = { ... };
```

### 2. 图片显示算法
```c
void LCD_DisplayImage(const uint8_t *image_data)
{
    uint16_t idx = 0;
    
    // 逐页扫描
    for (uint8_t page = 0; page < 8; page++) {
        BIOS_JLX12864_TRANS_CMD(0xB0 + page);  // 页地址
        BIOS_JLX12864_TRANS_CMD(0x10);         // 列高位
        BIOS_JLX12864_TRANS_CMD(0x00);         // 列低位
        
        // 逐列写入数据
        for (uint8_t col = 0; col < 128; col++) {
            BIOS_JLX12864_TRANS_DAT(image_data[idx++]);
        }
    }
}
```

### 3. 电池图标选择逻辑
```c
const uint8_t* LCD_GetBatteryIcon(uint8_t battery_percent)
{
    if (battery_percent >= 90) return BATTERY_ICON_4;  // 满格
    if (battery_percent >= 70) return BATTERY_ICON_3;
    if (battery_percent >= 40) return BATTERY_ICON_2;
    if (battery_percent >= 15) return BATTERY_ICON_1;
    return BATTERY_ICON_0;  // 低电量
}
```
