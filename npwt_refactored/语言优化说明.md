# 语言优化说明

**优化日期**: 2025-10-20  
**优化内容**: 移除俄语支持，仅保留英语  

---

## ✅ 已完成的优化

### 1. 移除俄语字符串引用

**修改文件**: `Drivers/Src/lcd_driver.c`

**变更**:
```c
// 优化前：
extern const unsigned char rus_model[];
extern const unsigned char rus_continuous[];
// ... 8个俄语字符串

void LCD_DisplayMode(WorkMode_e mode, uint8_t language)
{
    if (language == LANGUAGE_RUSSIAN) {
        PutStr(0, 0, rus_model);
    } else {
        LCD_DisplayString(0, 0, "Mode:");
    }
}

// 优化后：
// 完全移除俄语字符串引用

void LCD_DisplayMode(WorkMode_e mode)
{
    LCD_DisplayString(0, 0, "Mode:");
    // 只有英语显示
}
```

### 2. 简化函数接口

**修改文件**: `Drivers/Inc/lcd_driver.h`

**变更**:
```c
// 优化前：
void LCD_DisplayMode(WorkMode_e mode, uint8_t language);
void LCD_DisplayError(ErrorCode_e error, uint8_t language);

// 优化后：
void LCD_DisplayMode(WorkMode_e mode);  // 移除language参数
void LCD_DisplayError(ErrorCode_e error);  // 移除language参数
```

### 3. 更新数据结构

**修改文件**: `Core/Inc/system_types.h`

**变更**:
```c
// 优化前：
typedef struct {
    uint8_t language;  // 语言选择
    bool backlight_on;
    // ...
} UIData_t;

typedef struct {
    uint16_t pressure_setting;
    uint8_t language_setting;  // 语言设置
    // ...
} FlashConfig_t;

// 优化后：
typedef struct {
    // 移除了language字段
    bool backlight_on;
    // ...
} UIData_t;

typedef struct {
    uint16_t pressure_setting;
    // 移除了language_setting字段
    // ...
} FlashConfig_t;
```

### 4. 更新配置文件

**修改文件**: `Core/Inc/system_config.h`

**变更**:
```c
// 优化前：
#define LANGUAGE_RUSSIAN  0
#define LANGUAGE_ENGLISH  1

// 优化后：
#define LANGUAGE_ENGLISH_ONLY  1  // 仅英语模式
```

## 💡 为什么只保留英语

### 1. 简化代码
- 移除大量条件判断
- 减少代码复杂度
- 提高可维护性

### 2. 减少依赖
- 无需俄语字库文件
- 无需字符编码转换
- 编译更简单

### 3. 国际化
- 英语是国际通用语言
- 医疗设备常用英语界面
- 便于出口销售

### 4. 性能优化
- 减少Flash占用
- 减少字库数据
- 提高显示速度

## 🔄 如果需要恢复多语言支持

新架构的设计支持轻松添加多语言：

### 方法1：恢复language参数

```c
// 1. 在system_types.h中恢复language字段
typedef struct {
    uint8_t language;
    // ...
} UIData_t;

// 2. 在lcd_driver中恢复language参数
void LCD_DisplayMode(WorkMode_e mode, uint8_t language);

// 3. 添加语言字符串数组
const char *mode_strings[2][7] = {
    {"Mode:", "Standby", "Continuous", ...},  // 英语
    {"Режим:", "Ожидание", "Непрерывный", ...}  // 俄语
};
```

### 方法2：使用字符串表

```c
typedef struct {
    const char *english;
    const char *russian;
} StringPair_t;

const StringPair_t g_mode_strings[] = {
    {"Standby", "Ожидание"},
    {"Continuous", "Непрерывный"},
    // ...
};
```
